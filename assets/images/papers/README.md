# Paper Images

Each paper has one permanent global ID. Research-topic pages may reuse and reorder the same paper without changing its ID or image.

- `P1`: A Low-Rank Method for Vision Language Model Hallucination Mitigation in Autonomous Driving
- `P2`: VLM-MPC: Model Predictive Controller Augmented Vision Language Model for Autonomous Driving
- `P3`: Physical Enhanced Residual Learning (PERL) Framework for Vehicle Trajectory Prediction
- `P4`: Traffic Oscillation Mitigation with Physics-Enhanced Residual Learning-Based Predictive Control
- `P5`: Physics Enhanced Residual Policy Learning for Safety Cruising of Autonomous Vehicles
- `P6`: Physics-informed Neural Network for Cross-dynamics Vehicle Trajectory Stitching
- `P7`: AI-Enabled Digital Twin Framework for Safe and Sustainable Intelligent Transportation
- `P8`: Before and After Riding: Changing Comfort Attitude Towards Autonomous Shuttles from Perspectives as Riders, Drivers, and Pedestrians

Name each image with its paper ID first, followed by any readable description, for example:

- `P1_Low_Rank_VLM.jpg`
- `P5_Safety_Cruising.png`

JPG, JPEG, PNG, and WebP are accepted. The website binds the image to the paper using the leading paper ID.
